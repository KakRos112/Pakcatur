Tentang Pakcatur

Game catur hiburan di browser: lawan bot, ulasan permainan, dan main bareng teman.

Siapa pembuatnya?

Saya hanya mengemas berbagai karya open source menjadi satu game hiburan yang mudah dimainkan. Saya bukan insinyur utama maupun pembuat mesin caturnya. Kecerdasan bot berasal dari Stockfish, mesin catur open source yang dikembangkan bertahun-tahun oleh komunitas programmer dan pecatur dari seluruh dunia.

Kode tampilan, aturan, dan server game ini ditulis dengan bantuan asisten AI Claude Code dari Anthropic, lalu disusun dan diuji oleh pengemas.

Mesin catur: Stockfish

Bot dengan rating 1200 ke atas memakai Stockfish 10 versi JavaScript (stockfish.js 10.0.2). Mesin ini berjalan langsung di browser kamu lewat Web Worker, dan juga dipakai untuk bar evaluasi, petunjuk langkah, serta Ulasan Permainan.

Mesin bawaan untuk bot pemula

Bot level rendah (dan cadangan saat Stockfish gagal dimuat) memakai mesin kecil yang ditulis khusus untuk game ini (js/ai.js). Mesin ini menerapkan teknik klasik pemrograman catur yang dijelaskan di Chess Programming Wiki: alpha-beta, quiescence search, transposition table, null-move pruning, dan late move reduction. Bot pemula sengaja diberi "salah hitung" acak supaya terasa seperti manusia yang baru belajar.

Sumber referensi

Catur & mesin catur

  • Chess Programming Wiki — teknik pencarian langkah (alpha-beta, quiescence, null move, LMR, transposition table)
  • Simplified Evaluation Function (Tomasz Michniewski) — tabel nilai posisi bidak di mesin bawaan
  • Papan 0x88 — cara menyimpan papan dan membuat langkah di js/core.js
  • Perft Results — posisi uji untuk memastikan semua aturan langkah benar
  • Zobrist Hashing — deteksi pengulangan posisi
  • Universal Chess Interface (UCI) — protokol komunikasi dengan Stockfish
  • FIDE Laws of Chess — aturan resmi: rokade, en passant, promosi, seri 50 langkah, pengulangan 3 kali

Ulasan permainan

  • Lichess: Accuracy — rumus persentase menang dan akurasi langkah
  • Label langkah (Brilian, Terbaik, Blunder, dan lainnya) terinspirasi dari fitur Game Review di chess.com; aturan penilaiannya dibuat sendiri
  • Nama pembukaan mengikuti istilah umum dunia catur (klasifikasi ECO)

Teknologi web

  • Web Workers — menjalankan mesin catur tanpa membuat halaman macet
  • Server-Sent Events — lobi dan langkah mode online
  • Web Audio API — efek suara tanpa file audio
  • Fullscreen API — tombol layar penuh
  • Node.js — menjalankan server.js untuk mode online
  • Cloudflare Tunnel — membuka server ke internet (lihat DEPLOY.md)

Desain

  • Tampilan dan alur bermain terinspirasi dari chess.com dan lichess.org, tapi semua gambar avatar dan kodenya dibuat sendiri

Catatan

  • Pakcatur tidak berafiliasi dengan chess.com, Lichess, FIDE, maupun proyek Stockfish.
  • Nama bot memakai nama tokoh publik hanya untuk hiburan. Kalimat sapaannya karangan, bukan kutipan asli, dan avatarnya kartun umum yang tidak dibuat mirip wajah aslinya.
  • Rating bot hanya perkiraan dan tidak setara dengan rating resmi mana pun.
